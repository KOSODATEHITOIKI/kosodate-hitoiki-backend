# 運営の二段階認証

更新日：2026-10-15。Issue #17。運営者（管理画面・通報の対処）を、二段階認証（TOTP、認証アプリ）で守る仕組みと、管理者の手作業をまとめる。**決定済み**：管理画面は運営者のみ・二段階認証必須（Notion F-11）。**設計案**：下記の実現方法と手順は実装時の案。

## 1. 守り方（多重）

| 層 | 内容 |
|---|---|
| Supabase Auth | TOTPの登録（enroll）・検証（verify）を有効にする。検証に成功したセッションのJWTに、`aal: "aal2"`が付く |
| DB（RLS） | `is_admin()`が、`admin_users`への登録**と**`aal2`を要求する。運営者向けのRLS・ビュー（`reports`・`admin_report_queue`・`moderation_actions`の参照など）は、`aal1`のセッションでは何も見えない |
| Edge Function（`moderation`） | 運営者として登録されていない利用者には、機能の存在を明かさない（`404`）。登録されていても`aal2`でなければ`403`（`mfa_required`）。運営者のIDはトークンから取り、リクエスト本文のIDは使わない |
| DB関数（`moderation_apply`） | 渡された運営者のIDが`admin_users`にあるかを再確認する（Edge Functionの確認に頼りきらない）。運営者自身には警告・利用停止をかけられない |

`aal`は、Supabase Authが検証したトークンのクレームから読む（クライアントの自己申告ではない）。管理画面のUIは、二段階認証を済ませたあとのトークンでAPIを呼ぶ（フロントエンド側の担当）。

## 2. 管理者の手作業（dev・prodそれぞれ）

| 手順 | 内容 | 状態 |
|---|---|---|
| 1 | Supabaseの Authentication > Sign In / Providers（またはMFA）で、**TOTP（App Authenticator）を有効**にする。ローカルは`supabase/config.toml`の`[auth.mfa.totp]`で有効（クラウドは標準で有効のはずだが、ダッシュボードで確認する） | 未確認 |
| 2 | 運営者のアカウント（メールログイン）を、通常どおり登録する | 未実施 |
| 3 | 運営者の`user_id`を`admin_users`へ登録する。SupabaseのSQL Editorで次を実行する（**運営者の登録は、クライアントからは行えない**） | 未実施 |
| 4 | 運営者のアカウントで、認証アプリ（Google Authenticator等）に二段階認証を登録し、検証する（管理画面のUIが必要。UIができるまでは、supabase-jsの`auth.mfa.enroll`・`challenge`・`verify`で行う） | 未実施 |

```sql
-- 運営者の登録（user_idは、auth.usersのid）
insert into public.admin_users (user_id) values ('<運営者のuser_id>');
```

## 3. 検証

- 自動（CI）：`supabase/tests/functions/run.sh`の結合テストが、**本物のTOTP**（テスト内でRFC 6238のコードを計算）で`aal1`から`aal2`へ上げ、①`aal1`では通報一覧が見えず対処が`403`、②運営者でない人には`404`、③`aal2`で通報一覧・再表示・警告・利用停止ができることを確認する。
- 手動（外部設定のあと、devで）：運営者のアカウントで、`aal1`のトークンと`aal2`のトークンの両方で`POST /functions/v1/moderation/actions`を呼び、前者が`403`、後者が`200`になることを確認する。

## 4. 未決定

- **運営者が閲覧できる利用者情報の範囲**（メールアドレス等）、協力者を追加する場合の権限分け：未決定（Notion F-11）。現状は、運営者は通報・投稿・コメント・対処の記録を読める。
- **運営者のアカウントの紛失・TOTPの再設定手順**：未決定。最初の運営者は、SupabaseのSQL Editor（プロジェクトの管理者権限）で復旧する想定。
- **異議申立て・利用停止の早期解除**（`account_restrictions.lifted_at`の運用）：未決定。現状、早期解除する操作（API）はない。SQL Editorで`lifted_at`を設定する。
