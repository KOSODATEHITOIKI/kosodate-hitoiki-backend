## 1. Issue #7で決定し、資料へ反映済みの項目

以下はGitHub Issue #7およびその後の確認で決定済み。詳細は[バックエンド設計](バックエンド設計.md)・[データ設計案](データ設計案.md)を参照し、本表からは除外する。

- 共感：ログイン必須、共感ボタンと定型文を1つのリアクションに統一、受付終了後も利用可能。
- 反応モード：「話を聞きたい」から「ただ聞いてほしい」へ変更可能。既存コメントは残し新規コメント・返信を停止。
- コメント・返信：受付終了後も本人は編集可能（送信前チェックあり）、親コメント削除時は本文を「削除済み」に置換し返信は残す、表示順は古い順（返信は親の下）、返信先の投稿者へ通知（自分自身・重複通知はしない）。
- ニックネーム：全角半角・大文字小文字・前後空白を同一視、絵文字等は1文字として2〜12文字、旧名は他者30日間使用不可・本人は再利用可（変更自体は30日に1回）。
- 通報・一時非表示：同一通報者・同一対象は1件として扱う、再表示後は対応済み通報を再集計せず新規通報のみ運営が確認、一時非表示中はコメント・返信も隠し新規コメント・共感を停止、削除済み・一時非表示のコメントは件数に含めない。
- プロフィール本文（bio・child_age_range）の閲覧範囲：初期版は本人と運営者のみ（他のログイン済み利用者には見せない）。2026-09-30決定。
- アカウント画像：イラストを選ぶか、自分の画像をアップロードするかのどちらか一方を選べる（2026-09-30決定。形式・容量・公開範囲・確認方法の細目は[スキーマ定義](スキーマ定義.md)2節）。
- ニックネームの初回変更：登録直後の初回変更は制限しない（2026-09-30決定）。2回目以降は前回の変更から30日空ける。
- 複数アカウント：初期版は禁止も検出もしない（メールごとに1アカウントのみ）。2026-09-30決定。
- 利用停止の期間：段階的（初回7日→再発30日→再発以降は無期限）。停止中はログイン後の投稿・コメント・共感・通報を禁止し、既存投稿は公開を維持する。
- データ保持期間：通報対処記録は1年、バックアップは30日（Notion 6.2.3の例示を正式採用）。
- 送信前チェックAPI障害時の挙動：保存をブロックし、利用者に再試行を促す（安全側）。
- 登録・投稿制限の方式：登録直後は軽いレート制限（投稿・コメント件数の上限）を設け、具体的な日数・件数と新規登録の一時停止可否は設定テーブルで運営がトグルできるようにする。
